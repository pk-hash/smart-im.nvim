1. INTRODUCTION                                       *smart-im-introduction*

smart-im.nvim is a lightweight input method switcher for Neovim that
automatically remembers the last used input method per buffer and restores
it when you enter insert mode.

Key features:
- Per-buffer input method memory
- Mode-aware tracking (insert↔normal, terminal↔normal)
- Cross-platform support (macOS, Linux, Windows)
- Auto memory cleanup on buffer delete
- Zero dependencies

==============================================================================
2. REQUIREMENTS                                       *smart-im-requirements*

- Neovim >= 0.9.0
- One of the following input method tools:
  * macOS: im-select or macism
    - im-select: https://github.com/daipeihust/im-select
    - macism: https://github.com/laishulu/macism
  * Linux: ibus, fcitx-remote, or fcitx5-remote
  * Windows: im-select.exe

3. INSTALLATION                                       *smart-im-installation*

Using lazy.nvim: >lua
    {
      "yourusername/smart-im.nvim",
      event = "InsertEnter",
      config = function()
        require("smart-im").setup()
      end,
    }
<

Using packer.nvim: >lua
    use {
      "yourusername/smart-im.nvim",
      config = function()
        require("smart-im").setup()
      end,
    }
<

4. CONFIGURATION                                     *smart-im-configuration*

Setup the plugin with options: >lua
    require("smart-im").setup({
      -- Default input method (used in normal mode)
      default_im = "com.apple.keylayout.US",

      -- Enable debug logging
      debug = false,

      -- Custom commands (auto-detected if nil)
      get_im_cmd = nil, -- e.g., "macism" or "im-select"
      set_im_cmd = nil, -- e.g., "macism %s"
    })
<

                                                          *smart-im.config*
Configuration options:

    default_im              (string)
        Default input method identifier used in normal mode.
        Default: "com.apple.keylayout.US"

    debug                   (boolean)
        Enable debug logging.
        Default: false

    get_im_cmd              (string|nil)
        Command to get current input method. Auto-detected if nil.
        Default: nil (auto-detect)

    set_im_cmd              (string|nil)
        Command template to set input method. Use %s for IM placeholder.
        Auto-detected if nil.
        Default: nil (auto-detect)

                                                            *:SmartIMClear*
:SmartIMClear

6. API                                                         *smart-im-api*

                                                         *smart-im.setup()*
setup({opts})
    Initialize the plugin with configuration options.
    Parameters: ~
        {opts} (table|nil) Configuration options

                                                  *smart-im.get_current_im()*
get_current_im()
    Get the current input method identifier.
    Returns: ~
        (string|nil) Current IM identifier

                                                        *smart-im.set_im()*
set_im({im})
    Set the input method.
    Parameters: ~
        {im} (string) Input method identifier
    Returns: ~
        (boolean) Success status

                                                     *smart-im.remember_im()*
remember_im({ft})
    Remember the current IM for the specified buffer.
    Parameters: ~
        {ft} (integer|nil) Buffer number (uses current buffer if nil)

                                                      *smart-im.restore_im()*
restore_im({ft})
    Restore the remembered IM for the specified buffer.
    Parameters: ~
        {ft} (integer|nil) Buffer number (uses current buffer if nil)

                                                *smart-im.switch_to_default()*
switch_to_default()
    Switch to the default input method.

                                                    *smart-im.clear_memory()*
clear_memory({ft})
    Clear input method memory.
    Parameters: ~
        {ft} (integer|nil) Buffer to clear (clears all if nil)

                                                      *smart-im.get_state()*
get_state()
    Get all remembered input methods.
    Returns: ~
        (table) Table mapping buffers to IM identifiers

                                                            *smart-im.set()*
set({ft}, {im})
    Set IM for a specific buffer.
    Parameters: ~
        {ft} (integer) Buffer number
        {im} (string) Input method identifier

7. EXAMPLES                                               *smart-im-examples*

Basic setup: >lua
    require("smart-im").setup()
<

Linux IBus setup: >lua
    require("smart-im").setup({
      default_im = "xkb:us::eng",
    })
<

macOS with macism: >lua
    require("smart-im").setup({
      default_im = "com.apple.keylayout.US",
      get_im_cmd = "macism",
      set_im_cmd = "macism %s",
    })
<

Manual IM control: >lua
    local im = require("smart-im.im")
    local utils = require("smart-im.utils")

    -- Remember current IM
    im.remember()

    -- Restore saved IM
    im.restore()

    -- Get current IM
    local current = utils.get_current_im()
    print("Current IM: " .. current)
<

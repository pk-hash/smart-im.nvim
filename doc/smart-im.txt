1. INTRODUCTION                                       *smart-im-introduction*

smart-im.nvim is a lightweight input method switcher for Neovim that
automatically remembers the last used input method per buffer and restores
it when you enter insert mode.

Key features:
- Per-buffer input method memory
- Cross-platform support (macOS, Linux, Windows)
- Automatic IM restoration on InsertEnter
- Lua API for custom logic
- Zero dependencies

==============================================================================
2. REQUIREMENTS                                       *smart-im-requirements*

- Neovim >= 0.9.0
- One of the following input method tools:
  * macOS: im-select (https://github.com/daipeihust/im-select)
  * Linux: ibus, fcitx-remote, or fcitx5-remote
  * Windows: im-select.exe

3. INSTALLATION                                       *smart-im-installation*

Using lazy.nvim: >lua
    {
      "yourusername/smart-im.nvim",
      event = "InsertEnter",
      config = function()
        require("smart-im").setup()
      end,
    }
<

Using packer.nvim: >lua
    use {
      "yourusername/smart-im.nvim",
      config = function()
        require("smart-im").setup()
      end,
    }
<

4. CONFIGURATION                                     *smart-im-configuration*

Setup the plugin with options: >lua
    require("smart-im").setup({
      -- Default input method (fallback)
      default_im = "com.apple.keylayout.ABC",

      -- Restore previous IM for the buffer on InsertEnter
      restore_previous = true,

      -- Switch to default IM on InsertLeave
      switch_on_leave = true,

      -- Filetypes to exclude from per-buffer tracking
      exclude_filetypes = {}, -- e.g., { "TelescopePrompt", "help" }

      -- Optional predicate to exclude buffers from tracking
      -- exclude = function(bufnr) return false end,

      -- Events that trigger IM restore
      restore_events = { "InsertEnter" },

      -- Events that trigger IM remember
      remember_events = { "InsertLeave", "CmdlineLeave" },

      -- Custom commands (auto-detected if nil)
      get_im_cmd = nil, -- e.g., "im-select"
      set_im_cmd = nil, -- e.g., "im-select %s"
    })
<

                                                          *smart-im.config*
Configuration options:

    default_im              (string)
        Default input method identifier. This is used as fallback when no
        previous IM exists for a buffer.
        Default: "com.apple.keylayout.ABC"

    restore_previous        (boolean)
        Whether to restore the last used IM for the buffer when entering
        insert mode.
        Default: true

    switch_on_leave         (boolean)
        Whether to switch to default IM when leaving insert mode.
        Default: true

    exclude_filetypes       (table)
        List of filetypes to ignore (no remember/restore).
        Default: {}
        Example: { "TelescopePrompt", "help" }

    exclude                 (function|nil)
        Custom predicate that receives a buffer number and returns true to
        skip tracking for that buffer.
        Default: nil

    restore_events          (table)
        List of autocmd events that trigger IM restoration.
        Default: { "InsertEnter" }
        Example: { "InsertEnter", "CmdlineEnter" }

    remember_events         (table)
        List of autocmd events that trigger IM remember and switch to default.
        Default: { "InsertLeave", "CmdlineLeave" }
        Example: { "InsertLeave" } (only insert mode)

    get_im_cmd              (string|nil)
        Command to get current input method. Auto-detected if nil.
        Default: nil (auto-detect)

    set_im_cmd              (string|nil)
        Command template to set input method. Use %s for IM placeholder.
        Auto-detected if nil.
        Default: nil (auto-detect)

6. API                                                         *smart-im-api*

                                                         *smart-im.setup()*
setup({opts})
    Initialize the plugin with configuration options.
    Parameters: ~
        {opts} (table|nil) Configuration options

                                                  *smart-im.get_current_im()*
get_current_im()
    Get the current input method identifier.
    Returns: ~
        (string|nil) Current IM identifier

                                                        *smart-im.set_im()*
set_im({im})
    Set the input method.
    Parameters: ~
        {im} (string) Input method identifier
    Returns: ~
        (boolean) Success status

                                                     *smart-im.remember_im()*
remember_im({ft})
    Remember the current IM for the specified buffer.
    Parameters: ~
        {ft} (integer|nil) Buffer number (uses current buffer if nil)

                                                      *smart-im.restore_im()*
restore_im({ft})
    Restore the remembered IM for the specified buffer.
    Parameters: ~
        {ft} (integer|nil) Buffer number (uses current buffer if nil)

                                                *smart-im.switch_to_default()*
switch_to_default()
    Switch to the default input method.

                                                    *smart-im.clear_memory()*
clear_memory({ft})
    Clear input method memory.
    Parameters: ~
        {ft} (integer|nil) Buffer to clear (clears all if nil)

                                                      *smart-im.get_state()*
get_state()
    Get all remembered input methods.
    Returns: ~
        (table) Table mapping buffers to IM identifiers

                                                            *smart-im.set()*
set({ft}, {im})
    Set IM for a specific buffer.
    Parameters: ~
        {ft} (integer) Buffer number
        {im} (string) Input method identifier

7. EXAMPLES                                               *smart-im-examples*

Basic setup: >lua
    require("smart-im").setup()
<

Custom default IM: >lua
    require("smart-im").setup({
      default_im = "xkb:us::eng", -- Linux IBus
    })
<

Track only specific filetypes: >lua
    require("smart-im").setup({
      exclude_filetypes = { "TelescopePrompt", "help" },
    })
<

Disable auto-switch on InsertLeave: >lua
    require("smart-im").setup({
      switch_on_leave = false,
    })
<

Manual IM management: >lua
    local smart_im = require("smart-im")

    -- Set Chinese IM for current buffer
    smart_im.set(0, "com.apple.inputmethod.SCIM.ITABC")

    -- Get current IM
    local current = smart_im.get_current_im()
    print("Current IM: " .. current)

    -- Clear markdown memory
    smart_im.clear_memory("markdown")
<

Custom commands: >lua
    require("smart-im").setup({
      get_im_cmd = "custom-im-get",
      set_im_cmd = "custom-im-set %s",
    })
<
